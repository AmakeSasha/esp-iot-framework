# Relay Control

An example of controlling a relay via a web interface.

![screenshot0.png](./assets/screenshot0.png)

## Relay connection pins (Supports Low-Level trigger or High-Level trigger modules)
* `RELAY_PIN` -> GPIO 13
* `GND` -> Common ground
